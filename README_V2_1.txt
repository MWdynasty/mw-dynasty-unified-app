MW Dynasty Unified App V2.1 — Stadium Luxe Design

Approved design direction:
- User-supplied MW Dynasty stadium role-selection artwork is the master visual language.

- Existing app behavior, auth, Supabase wiring, coach vetting, and program data are preserved.
