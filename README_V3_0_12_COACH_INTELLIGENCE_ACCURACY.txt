MW Dynasty V3.0.12 – Coach Intelligence Capability Accuracy

This update corrects Coach MW's Coach Intelligence capability language and data access.

Changes:
- Removed Session RPE from Coach Intelligence capability claims.
- Removed rep-by-rep sprint timing / MW target comparison claims from Coach Intelligence.
- Coach Intelligence uses quick pace check-ins, workout completion, attendance, PRs, flags, program position, strength check-ins/logs, and progression context.
- Detailed timed sprint reps, target-vs-actual analysis, consistency, and first-to-last drop-off remain MW Sprint Performance only.
- Coach MW now receives the authenticated coach tier and loads detailed sprint-rep context only for MW Sprint Performance.

No pricing, invitation, messaging, or program prescription logic was changed in this update.
