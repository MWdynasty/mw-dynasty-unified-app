MW Dynasty Coach V11.23 — Founder Approval + Server-Locked Coach Tiers

Built from V11.22.
- Founder-only Coach Applications workspace.
- Founder can review, approve/reject, assign Core / Intelligence / MW Sprint Performance, and send a secure Supabase invitation.
- Coach tier is read from server-side coach_access_entitlements after login.
- Coaches can no longer switch their own tier from localStorage or the UI.
- Founder retains tier preview for QA.
- New vetted coach invitations provision a Coach profile instead of an Athlete profile.
- Existing active development coach accounts were grandfathered to MW Sprint Performance to avoid build lockout.
- Public coach applications still do not create accounts.
